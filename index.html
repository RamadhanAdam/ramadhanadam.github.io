Research

Open-world malware detection master's thesis, 2025 to now

A malware classifier is trained on the families it has seen, so it gives every new family the name of an old one. I am building detection that can also say "unknown", and then learn the new family from a few examples. The input is the program itself: an encoder reads a Windows executable region by region, as the PE format lays it out, with an attention bias that tells it each region's type, byte entropy and size. It is pretrained without labels, by contrastive learning on the 9.9 million malware binaries of SOREL-20M. On top of it, each known family is described by several prototypes, and a file far from all of them is rejected.

In Hiroshima I train the byte-level encoder on the lab's GPUs and evaluate it on BODMAS, a labelled dataset it never saw during pretraining, against a second encoder built on EMBER2024's static features. The next steps are grouping the rejected files so an analyst can confirm a new family, and adding that family from one to twenty examples without retraining.

Supervised by Dr. Albert Njoroge Kahira and Dr. Mulang' Onando (PAUSTI) and Assoc. Prof. Junjun Zheng (Hiroshima University).

Federated intrusion detection for vehicles in progress

GraMa replaces the CNN and recurrent layers of a federated intrusion detector for in-vehicle networks with a graph attention network, for how ECUs connect, and a Mamba state-space model, for how traffic unfolds over time. The server clusters client updates with HDBSCAN to keep poisoned clients out of the global model. code
